# PHARAOH TEC — Global Technology Corporation Website (v4.0 Flagship)

An enterprise-grade, bilingual (Arabic / English) technology corporation website built to match the visual and interactive standards of top global tech giants.

## Flagship Features (v4.0)
- **Live System Status Top Bar:** Displays real-time operational status (`99.99% Uptime`), HQ coordinates, and direct email (`kareemabdelrazek289@gmail.com`).
- **Interactive Neural Network Canvas & 3D Holographic Core:** Live animated particle network in the hero section paired with an interactive 3D-tilting command core and live telemetry HUD panels.
- **Command Palette (`Ctrl+K` / `⌘K`):** Quick-jump keyboard navigation modal just like modern developer & enterprise platforms.
- **Product Ecosystem & Technical Specs Modal:** Interactive product cards with category filtering and a modal window displaying technical architecture specs for each platform.
- **Technology Architecture & Strategic Roadmap:** Dedicated sections showcasing the company's frontend, AI, and zero-trust security stack alongside the 2026–2030 roadmap.
- **Direct Executive Contact Desk:** Pre-filled `mailto:` integration to `kareemabdelrazek289@gmail.com` plus one-click copy buttons.

## Deploy on GitHub Pages
1. Upload `index.html`, `style.css`, `script.js`, and `README.md` to your repository root.
2. Go to **Settings → Pages**, choose `main` branch and `/ (root)`, and click **Save**.
